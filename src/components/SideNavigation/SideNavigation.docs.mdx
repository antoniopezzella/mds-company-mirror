# Side Navigation

<Subtitle>Vertical navigation for application shells and dashboards.</Subtitle>

<Description>
Use Side Navigation to organize top-level areas and deep pages in enterprise apps. It supports an active item state and collapsible groups (nested items). Prefer short labels and meaningful icons.
</Description>

## Anatomy

- Container panel (rail or expanded panel depending on layout)
- Navigation list
- Item: icon, label, active indicator
- Group header (disclosure): caret + label
- Nested items (optional)
- Divider / Section header (optional)
- Support CTA (optional)

## Usage

- Place the component inside the app shell (fixed left column).
- Define items with optional `subItems` for collapsible groups.
- Mark the current route with `active: true`.
- Use the support CTA for help/contact if relevant to the product.

## Accessibility

- Wrap the component in a `<nav aria-label="Primary">` landmark where appropriate.
- Use `aria-current="page"` for the active item (or the component’s selected styling) and ensure a visible focus ring.
- Keyboard:
  - Tab/Shift+Tab move focus into/out of the nav
  - Up/Down move between items
  - Enter/Space activate item or toggle a group
  - Left/Right Collapse/Expand when focus is on a group header (if applicable)
- Ensure 44x44px min touch targets and sufficient color contrast.

## Theming and roles

- Color via roles (reference): surface canvas, interactive primary (active), text default/onAccent for labels.
- Gaps/spacing via the design system spacing function and grid utilities (e.g., `.gap-*`).
- Avoid hard-coded hex values. Follow the roles in `src/theme/roles.ts` when styling this component.

## Content guidelines

- Short, scannable labels (avoid wrapping when possible)
- Group related items; don’t exceed two levels of nesting
- Use consistent, recognizable icons
- Keep the order stable between sessions

## API

The component currently accepts:

- `items: { label: string; icon?: React.ReactNode; active?: boolean; subItems?: SideNavItem[] }[]`
- `onSupport?: () => void`

## Migration tips

- If you’re moving from a pure MUI Drawer/List setup, start by mapping to the `items` shape with `subItems` for collapsible sections.
- For routing, control the `active` state from your router and pass updated `items` to the component.
