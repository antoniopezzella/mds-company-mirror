# Button

A consistent, accessible button built on MUI, wired to our role-based color system and spacing scale. Typography is sourced from our SCSS variables (`--typo-button-*`).

## Quick reference

- Variants: `primary` (contained), `secondary` (outlined), `text` (no fill)
- Tones: `default`, `danger`, `success`
- Sizes and heights: `sm` 32px, `md` 48px (default), `lg` 56px
- Icon gap: 8px (auto; no gap in icon-only)
- Corner radius: 2px
- Icon-only: square buttons (32/48/56) with centered glyph

## When to use

- Primary actions on a page or card
- Secondary/tertiary actions (outlined or text) when visual weight should be reduced
- Destructive or success actions via the `tone` prop

## Variants

- `primary` (contained)
- `secondary` (outlined)
- `text`

## Tones

- `default` (role-based colors)
- `danger` (maps to MUI `error` palette)
- `success` (maps to MUI `success` palette)

## Sizes

- `sm`: 4px y / 12px x (total height 32)
- `md`: 12px y / 20px x (total height 48)
- `lg`: 16px y / 24px x (total height 56)

Sizing model
- Heights are fixed (32/48/56) using box-sizing: border-box so outlined borders don’t increase total size.

Other specs
- Icon gap: 8px
- Corner radius: 2px

## Accessibility

- Always provide an accessible name. For icon-only, use `aria-label` to describe the action.
- Keyboard focus shows a 2px ring using the `focus.ring` role.
- Use `disabled` to prevent interaction; it also communicates state to assistive tech.
- Touch target: prefer `md` (48px) or `lg` (56px) for touch surfaces. Use `sm` (32px) only in dense UIs.
- Contrast: primary uses `text.onAccent` on `interactive.primary`; danger uses `text.onDanger`.

## Engineering notes

- Colors: use getRoleColor() indirectly via the component; don’t import primitives/semantic tokens in feature code.
- Sizing: fixed heights 32/48/56 with border-box; padding driven by theme spacing; icon gap 8px.
- Icon-only: center the glyph and remove default icon margins; always set aria-label.
- Theming: typography comes from CSS variables; button text uses Noto Sans Medium (500).
- Tests: see Storybook play checks in Button.stories.tsx for focus, click, and size assertions.

## Content guidelines

- Keep labels short and action-oriented: “Save,” “Continue,” “Invite.”
- Sentence case (capitalize first word only) unless brand exception applies.
- Avoid punctuation and trailing ellipses unless it opens a modal or new flow.
- Icons should reinforce meaning, not duplicate it. Prefer leading icons for actions; use trailing for navigation (“Next”).
- Icon-only is for very constrained UI; ensure `aria-label` communicates the action.

## Role-based colors (reference)

- Default primary: `interactive.primary` with `hover`/`active` states; text: `text.onAccent`.
- Danger tone: `interactive.danger` with `hover`/`active` states; text: `text.onDanger`.
- Focus ring: `focus.ring`.

## Notes

- Colors must be set via role names; do not use primitives or semantic tokens directly in components.
- Spacing uses `theme.spacing()` indices; avoid raw pixel values.
- Typography for buttons is defined in `src/styles/_typography.scss` and consumed by the theme.
- Active state uses role `interactive.primary.active` (light: #001f52; dark: #001538).
