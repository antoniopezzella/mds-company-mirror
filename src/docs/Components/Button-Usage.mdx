# Button Usage

Practical guidance for the primary action component. This page supplements the autogenerated API docs.

## Primary Action
Use a contained primary button for the dominant action in a view.

<div style={{ display: 'flex', gap: 12 }}>
	<DSButton>Primary action</DSButton>
</div>

## Variants
Avoid stacking multiple primary buttons. Use secondary style for less prominent adjacent actions.

<div style={{ display: 'flex', gap: 12 }}>
	<DSButton variant="secondary">Secondary action</DSButton>
	<DSButton variant="text">Learn more</DSButton>
	<DSButton tone="danger">Delete</DSButton>
</div>

## States & Tones
Tone communicates semantic intent (e.g., danger for destructive, success for confirmation). Disabled indicates inactionable state.

<div style={{ display: 'flex', gap: 12, flexWrap: 'wrap' }}>
	<DSButton tone="danger">Delete</DSButton>
	<DSButton tone="success">Save</DSButton>
	<DSButton disabled>Disabled</DSButton>
</div>

## Playground
Try different `variant`, `tone`, and `size` props in your app code:

```tsx
<DSButton>Primary</DSButton>
<DSButton variant="secondary">Secondary</DSButton>
<DSButton variant="text">Learn more</DSButton>
<DSButton tone="danger">Delete</DSButton>
```

## Accessibility

### A11y Do / Don't
**Do** keep a visible focus indicator on all button variants.

**Don’t** replace a disabled actionable button with a non-button element (preserve semantics) or rely solely on color to convey destructive actions.

## Copy & paste starters

```tsx
import DSButton from 'src/components/Button/Button';

export function Primary() {
	return <DSButton>Primary action</DSButton>;
}

export function Secondary() {
	return <DSButton variant="secondary">Secondary action</DSButton>;
}

export function Danger() {
	return <DSButton tone="danger">Delete</DSButton>;
}
```

```tsx
// Icon-only
import DSButton from 'src/components/Button/Button';
import SaveIcon from '@mui/icons-material/Save';

export function IconOnly() {
	return <DSButton aria-label="Save" iconOnly startIcon={<SaveIcon />} />;
}
```

// Full-width
import DSButton from 'src/components/Button/Button';

		</div>
	);
}
