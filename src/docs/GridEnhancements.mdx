## 🎯 Subgrid Utilities (Future-Ready)

### Perfect Alignment Across Components

Subgrid allows child grids to inherit their parent's grid tracks for perfect alignment. **Note**: Currently supported in Firefox and Safari, coming to Chrome soon.

<div className="demo-section">
  <h4>Card Grid with Aligned Content</h4>
  <div className="container">
    <div className="row gap-6" style={{gridTemplateRows: 'auto 1fr auto'}}>
      <div className="col-4 subgrid-rows" style={{display: 'grid', gridRow: '1 / -1', background: '#f8f9fa', borderRadius: 8, padding: 16}}>
        <h5 style={{margin: '0 0 8px 0', background: '#e3f2fd', padding: 8, borderRadius: 4, textAlign: 'center'}}>Header</h5>
        <div style={{background: 'white', padding: 12, borderRadius: 4, flexGrow: 1}}>
          Variable content length. This content can be short or long, but headers and footers will align perfectly across all cards.
        </div>
        <button style={{marginTop: 8, background: '#1976d2', color: 'white', border: 0, padding: '8px 16px', borderRadius: 4}}>Action</button>
      </div>
      <div className="col-4 subgrid-rows" style={{display: 'grid', gridRow: '1 / -1', background: '#f8f9fa', borderRadius: 8, padding: 16}}>
        <h5 style={{margin: '0 0 8px 0', background: '#e3f2fd', padding: 8, borderRadius: 4, textAlign: 'center'}}>Header</h5>
        <div style={{background: 'white', padding: 12, borderRadius: 4, flexGrow: 1}}>
          Short content.
        </div>
        <button style={{marginTop: 8, background: '#1976d2', color: 'white', border: 0, padding: '8px 16px', borderRadius: 4}}>Action</button>
      </div>
      <div className="col-4 subgrid-rows" style={{display: 'grid', gridRow: '1 / -1', background: '#f8f9fa', borderRadius: 8, padding: 16}}>
        <h5 style={{margin: '0 0 8px 0', background: '#e3f2fd', padding: 8, borderRadius: 4, textAlign: 'center'}}>Header</h5>
        <div style={{background: 'white', padding: 12, borderRadius: 4, flexGrow: 1}}>
          Medium length content that demonstrates how subgrid keeps headers and footers aligned.
        </div>
        <button style={{marginTop: 8, background: '#1976d2', color: 'white', border: 0, padding: '8px 16px', borderRadius: 4}}>Action</button>
      </div>
    </div>
  </div>

  ```html
  <!-- Parent grid with implicit rows -->
  <div className="row gap-6" style={{gridTemplateRows: 'auto 1fr auto'}}>
    <!-- Child grids inherit row structure via subgrid -->
    <div className="col-4 subgrid-rows">
      <h5>Header</h5>
      <div>Variable content...</div>
      <button>Action</button>
    </div>
    <div className="col-4 subgrid-rows">
      <h5>Header</h5>
      <div>Short content.</div>
      <button>Action</button>
    </div>
    <div className="col-4 subgrid-rows">
      <h5>Header</h5>
      <div>Medium content...</div>
      <button>Action</button>
    </div>
  </div>
  ```

  ### Subgrid Utility Classes

  | Class | Function |
  |-------|----------|
  | `.subgrid-cols` | Inherit parent's column tracks |
  | `.subgrid-rows` | Inherit parent's row tracks |
  | `.subgrid-both` | Inherit both column and row tracks |
  | `.subgrid-*-{bp}` | Responsive subgrid utilities |
</div>

## 🚀 Migration Guide

### Upgrading from Previous Version

1. **XXL Breakpoint**: No breaking changes, just additional utilities
2. **Aspect Ratios**: Replace custom CSS with utility classes
3. **Subgrid**: Progressive enhancement - add when browser support is ready
4. **Extended Spacing**: Use new `.gap-28` and `.gap-32` for large layouts

## 📚 Best Practices

### Performance Optimization
- Use XXL breakpoint sparingly for ultra-wide specific layouts
- Combine aspect-ratio with object-fit for images
- Prefer CSS Grid over flexbox for main layout structure

### Design Consistency  
- Use consistent spacing scales across breakpoints
- Maintain aspect ratios for visual rhythm
- Plan for subgrid adoption in component libraries

### Enterprise Considerations
- XXL breakpoint perfect for financial dashboards and data visualization
- Extended spacing improves readability on large monitors
- Aspect ratios ensure consistent media presentation
