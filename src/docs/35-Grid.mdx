# Grid

A lightweight 12-column grid aligned to the 4px base with 8px gutters and responsive breakpoints. Built with CSS Grid and Sass utilities.

Columns: 12 • Base: 4px • Gutters: 8px • Breakpoints: xs, sm 600, md 900, lg 1200, xl 1536 • Container max: sm 580, md 860, lg 1140, xl 1440

## Usage

Import once (already wired globally in Storybook):

```scss
@use '../styles/grid' as *;
```

### 12px grid spacing (gap-3)

Use the 12px step via `.gap-3` or `style={{ '--mds-grid-gap': '12px' }}`.

  <div class="col-4">12px gap</div>
  <div class="col-4">12px gap</div>
  <div class="col-4">12px gap</div>
</div>

### Bootstrap-style helpers (familiarity)

We provide optional aliases inspired by Bootstrap for easier migration:

- Equal-width columns per row: `.row-cols-N` (N=1..6), with responsive variants `.row-cols-sm-N`, `.row-cols-md-N`, etc.
- Gap aliases: `.g-*`, `.gx-*`, `.gy-*` mirroring our `.gap-*`, `.gap-x-*`, `.gap-y-*`.

Note: Our canonical API is the `.col-*`, `.gap-*`, `.gap-x-*`, `.gap-y-*` set. The aliases are provided for familiarity and smoother adoption.

## Utilities

- Columns: `.col-1`..`.col-12`, responsive: `.col-sm-6`, `.col-md-4`, `.col-lg-3`, `.col-xl-2`
- Offsets: `.offset-1`..`.offset-11`, responsive equivalents
- Gaps: `.gap-1` (4px), `.gap-2` (8px), `.gap-3` (12px), `.gap-4` (16px), `.gap-6` (24px), `.gap-8` (32px)
- Directional gaps: `.gap-x-*` (column-gap) and `.gap-y-*` (row-gap)
- Alignment: `.align-{start|center|end}`, `.justify-{start|center|end}` for items, and `.content-justify-*` / `.content-align-*` for grid tracks
- Start position: `.start-N` to place an item at a specific grid track (with responsive variants)
- Fluid container: `.container-fluid` uses full width with consistent horizontal padding

### Auto-fit cards grid

When you don’t know how many cards fit per row, use the auto grid:

```html
<div class="row-auto" style="--mds-grid-col-min: 220px">
  <div class="card">A</div>
  <div class="card">B</div>
  <div class="card">C</div>
  <div class="card">D</div>
  <div class="card">E</div>
  <div class="card">F</div>
  <!-- more cards -->
  </div>
```

Live preview

<div className="row-auto" style={{ '--mds-grid-col-min': '220px', border: '1px solid #e5e7eb', padding: 8, borderRadius: 6 }}>
  {Array.from({ length: 9 }).map((_, i) => (
    <div key={i} className="card" style={{ background:'#f9f7fb', padding: 12, textAlign: 'center', borderRadius: 4 }}>Card {i+1}</div>

## Customize

Override defaults before importing:

```scss
$base-unit: 0.25rem; // 4px at 16px root
$gutter: 0.5rem;     // 8px at 16px root
$columns: 12;
@use '../styles/grid' as *;
```

Adjust `$breakpoints` and `$container-max` for different responsive behavior.

### Runtime tuning via CSS variables

You can tune grid gaps and min column width at runtime per section without recompiling Sass:

```html
<div class="row" style="--mds-grid-gap: 12px">…</div>
<div class="row-auto" style="--mds-grid-col-min: 240px">…</div>
```

This is helpful for special layouts (e.g., tighter gaps on dense dashboards) while keeping defaults aligned to the design tokens.
