## 👥 For Designers

### What You Can Do

- ✅ **Create responsive layouts** that adapt from mobile to ultra-wide (4K+)
- ✅ **Build dashboard widgets** with different heights and aspect ratios
- ✅ **Design card grids** that auto-fit to any screen size
- ✅ **Control spacing** from 4px to 128px (enterprise-scale)
- ✅ **Align content** horizontally and vertically with subgrid
- ✅ **Reorder elements** visually without changing HTML
- 🆕 **Ultra-wide layouts** for 1920px+ displays
- 🆕 **Consistent aspect ratios** across all components
- 🆕 **Future-proof alignment** with subgrid utilities

### Design Tokens

```
Breakpoints:
  xs: 0px      (mobile)
  sm: 576px    (tablet portrait)
  md: 768px    (tablet landscape)
  lg: 992px    (desktop)
  xl: 1200px   (large desktop)
  xxl: 1400px  (ultra-wide)

Containers:
  .container: 100% width up to 1320px max (centered)
  .container-fluid: 100% width (full)

Spacing Scale:
  gap-1: 4px     gap-9: 36px    gap-20: 80px
  gap-2: 8px     gap-10: 40px   gap-24: 96px
  gap-3: 12px    gap-12: 48px   gap-28: 112px (new)
  gap-4: 16px    gap-16: 64px   gap-32: 128px (new)
  gap-6: 24px    gap-8: 32px    + responsive variants
  
Aspect Ratios:
  .aspect-square   (1:1)    .aspect-3-2      (3:2)
  .aspect-video    (16:9)   .aspect-21-9     (21:9)
  .aspect-4-3      (4:3)    .aspect-auto     (reset)
  
Subgrid (Future):
  .subgrid-cols, .subgrid-rows, .subgrid-both
  + responsive variants for all breakpoints
```

```html
  <div class="col-4 subgrid-rows">
    <h4>Header</h4>
    <p>Short.</p>
    <button>Action</button>
  </div>
  <div class="col-4 subgrid-rows">
    <h4>Header</h4>
    <p>Medium length content.</p>
    <button>Action</button>
  </div>
```

```tsx
<div className="row gap-6" style={{gridTemplateRows: 'auto 1fr auto'}}>

      <h4>{product.title}</h4>
      <p>{product.description}</p>
      <button>Buy Now</button>
    </div>
  ))}
</div>
```

## Enhanced Utilities Reference

### Columns & Responsive
- **Columns**: `.col-1`..`.col-12`, responsive: `.col-sm-6`, `.col-md-4`, `.col-lg-3`, `.col-xl-2`, **`.col-xxl-*`**
- **Auto columns**: `.col` (equal width), `.col-auto` (content-based)
- **Custom grids**: `.grid-cols-1` to `.grid-cols-12`, responsive: `.grid-cols-{bp}-{n}`
- **Presets**: `.grid-auto-fit-{xs|sm|md|lg}`, `.grid-cols-sidebar`, `.grid-cols-two-thirds`

### Spacing (Enhanced Scale)
- **Standard**: `.gap-1` (4px), `.gap-2` (8px), `.gap-3` (12px), `.gap-4` (16px), `.gap-6` (24px), `.gap-8` (32px)
- **Extended**: `.gap-9` (36px), `.gap-10` (40px), `.gap-12` (48px), `.gap-16` (64px), `.gap-20` (80px), `.gap-24` (96px)
- **🆕 Enterprise**: **`.gap-28` (112px)**, **`.gap-32` (128px)**
- **Directional**: `.gap-x-*` (column-gap) and `.gap-y-*` (row-gap)
- **Responsive**: All gaps support `.gap-{bp}-{n}` (including **`.gap-xxl-*`**)

### 🆕 Aspect Ratios
- **`.aspect-square`** (1:1) - Perfect for profile images, icons
- **`.aspect-video`** (16:9) - Video players, hero images  
- **`.aspect-4-3`** (4:3) - Traditional photography
- **`.aspect-3-2`** (3:2) - Modern photography
- **`.aspect-21-9`** (21:9) - Ultra-wide content
- **`.aspect-auto`** - Reset to natural ratio

### 🆕 Subgrid (Future-Ready)
- **`.subgrid-cols`** - Inherit parent's column tracks
- **`.subgrid-rows`** - Inherit parent's row tracks  
- **`.subgrid-both`** - Inherit both column and row tracks
- **Responsive**: All subgrid utilities support `.subgrid-{type}-{bp}` variants

### Containers
- **`.container`** - Responsive centered container (540px → 1800px max-width)
- **`.container-fluid`** - Full-width container with consistent padding
- **🆕 Container queries**: `.container-query`, `.container-query-size` (future-ready)

### Alignment & Layout
- **Item alignment**: `.align-{start|center|end}`, `.justify-{start|center|end}`
- **Content alignment**: `.content-justify-*` / `.content-align-*` for grid tracks
- **Row spanning**: `.row-span-1` to `.row-span-6`, `.row-span-full`
- **Column spanning**: `.col-span-1` to `.col-span-12`, `.col-span-full`
- **Grid flow**: `.grid-flow-{row|col|dense}`

### Offsets & Positioning  
- **Offsets**: `.offset-1`..`.offset-11`, responsive: `.offset-{bp}-{n}`
- **Start position**: `.start-{n}` to place item at specific grid track
- **Responsive variants**: All positioning supports breakpoint variants

### Visibility & Ordering
- **Hide/Show**: `.hidden-{bp}`, `.visible-{bp}`
- **Ordering**: `.order-0` to `.order-12`, `.order-first`, `.order-last`
- **Responsive ordering**: `.order-{bp}-{n}`, `.order-{bp}-first`, `.order-{bp}-last`

## Tips & Best Practices

**Mobile-First Approach**
- Start with mobile layout (`.col-12`), then add breakpoints
- Example: `.col-12 .col-md-6 .col-lg-4` → Stack → 2 cols → 3 cols

**Performance**
- Use `.grid-auto-fit-md` for responsive cards instead of multiple breakpoints
- Prefer `.col` for equal-width layouts (simpler than `.col-{1-12}`)

**Accessibility**
- Use `.order-*` to reorder visually, but keep DOM order logical for screen readers
- Ensure sufficient color contrast in custom backgrounds

**Debugging**
- Add borders temporarily: `.row { border: 2px solid red; } .col { border: 1px solid blue; }`
- Use browser DevTools Grid Inspector to visualize layout

### ⚡ Performance Tips

**Fastest Grid Patterns:**
1. **`.container` + `.row` + `.col-*`** - Most optimized
2. **`.grid-auto-fit-md`** - Auto-responsive without media queries
3. **`.col` (no number)** - Equal-width, minimal CSS

**Avoid These:**
- ❌ Nested `.container` inside `.container`
- ❌ Using `.row` without `.col-*` children
- ❌ Mixing flexbox and grid utilities on same element

### 🔧 Troubleshooting Common Issues

**Grid Not Working?**
1. ✅ Check if `.row` has `.col-*` children
2. ✅ Verify total columns don't exceed 12
3. ✅ Ensure no typos in class names
4. ✅ Check responsive order with DevTools

**Layout Breaking on Mobile?**
1. ✅ Use `.col-12` for mobile-first
2. ✅ Test with DevTools mobile view  
3. ✅ Check if content overflow is hidden
4. ✅ Verify touch-friendly tap targets (44px minimum)

**XXL Not Working?**
1. ✅ Check viewport is actually 1920px+
2. ✅ Verify no conflicting CSS
3. ✅ Test with browser zoom at 100%
4. ✅ Check if other utilities override
