# Grid System

The standard grid for all new work: plain [Tailwind CSS](https://tailwindcss.com/docs/grid-template-columns) grid utilities. No custom classes, no separate import — `grid`, `grid-cols-*`, `gap-*`, and `col-span-*` are built into Tailwind itself and already available everywhere in this app.

## For Designers

### What this gives you

- A 12-column grid at any breakpoint, with `col-span-*` to size an element across N columns
- A spacing scale from 0 to 24rem (`gap-0` through `gap-96`, on the same 4px base as the rest of the design system)
- Five responsive breakpoints, applied with a prefix (`md:grid-cols-4`), not a suffix
- Auto-fit/auto-fill columns for card grids where you don't know the count in advance
- A centered `container` utility, customized for this brand to cap at 1540px (matching the legacy system's own max width, so pages don't visually jump if they mix eras)

### Design tokens

```
Breakpoints (real Tailwind defaults — unmodified in this project):
  sm:  640px
  md:  768px
  lg:  1024px
  xl:  1280px
  2xl: 1536px

Container (tailwind.config.js — the one customization in this system):
  centered: yes
  padding:  16px (default) → 24px (md) → 32px (lg)
  2xl cap:  1540px  ← note: not 1536px. The container's own max-width
                       is set slightly wider than the bare 2xl breakpoint,
                       to match the legacy grid's 1540px container exactly.

Spacing scale (gap-N — 0.25rem/4px base, same grid as everywhere else in MDS):
  gap-0: 0px      gap-4: 16px     gap-12: 48px    gap-24: 96px
  gap-1: 4px      gap-5: 20px     gap-14: 56px    gap-32: 128px
  gap-2: 8px      gap-6: 24px     gap-16: 64px    gap-40: 160px
  gap-3: 12px     gap-8: 32px     gap-20: 80px    gap-48: 192px
```

## For Developers

### Nothing to install

Tailwind's grid utilities are generated on demand from whatever classes appear in your JSX — there's no import, no SCSS `@use`, no separate build step. Just write the class names.

```tsx
// No import needed — Tailwind scans src/**/*.{ts,tsx} automatically
<div className="grid grid-cols-12 gap-6">...</div>
```

### The one real customization

`tailwind.config.js`'s `theme.container` is customized so the `container` utility centers, applies the same 16/24/32px padding steps the rest of this app uses, and caps at exactly **1540px** at the `2xl` tier — everything else (`grid-cols-*`, `gap-*`, the `sm/md/lg/xl/2xl` breakpoints themselves) is stock Tailwind, unmodified.

## Grid, Stack, or PageShell?

Three tools, and picking the wrong one is the usual cause of layout that
fights back:

| Situation | Use | Why |
| --- | --- | --- |
| Children in **one direction** with even spacing | `<Stack>` / `<Inline>` | The gap is type-checked against the DS scale; `gap={7}` will not compile |
| **Two-dimensional** layout — columns that reflow, spans, ordering | Grid utilities on this page | A grid is what this is. Three nested stacks faking one is harder to read and to change |
| The **page frame** — header, sidebar, main | `<PageShell>` | It already handles the responsive sidebar, the mobile scrim, and the `min-w-0` chain that stops wide tables scrolling the page sideways |

`Stack` and grid compose freely: a `Stack` of sections where one section is a
`grid grid-cols-3` is the normal shape of a dashboard page.

## Common Patterns

### Pattern 1 — Two-column layout (main + sidebar)

**When to use**: main content + sidebar layouts, the most common page shape.

```tsx
<div className="grid grid-cols-4 gap-4 md:grid-cols-12">
  <div className="col-span-4 md:col-span-8">Main content</div>
  <div className="col-span-4 md:col-span-4">Sidebar</div>
</div>
```

<div className="grid grid-cols-4 gap-4 md:grid-cols-12" style={{ border: '1px solid #e5e7eb', padding: 8, borderRadius: 6, marginTop: 12 }}>
  <div className="col-span-4 md:col-span-8" style={{ background:'#e5edf4', padding:16, color:'#1a1a1a' }}>
    <strong>Main Content</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '14px' }}>66% width from md up, 100% below</p>
  </div>
  <div className="col-span-4 md:col-span-4" style={{ background:'#c7edff', padding:16, color:'#1a1a1a' }}>
    <strong>Sidebar</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '14px' }}>33% width from md up, 100% below</p>
  </div>
</div>

### Pattern 2 — Responsive card grid, auto-fit

**When to use**: product cards, blog posts, image galleries — any count of cards, unknown in advance.

```tsx
<div className="grid gap-4" style={{ gridTemplateColumns: 'repeat(auto-fit, minmax(220px, 1fr))' }}>
  {products.map((product) => <ProductCard key={product.id} {...product} />)}
</div>
```

<div className="grid gap-4" style={{ gridTemplateColumns: 'repeat(auto-fit, minmax(220px, 1fr))', border: '1px solid #e5e7eb', padding: 8, borderRadius: 6, marginTop: 12 }}>
  {Array.from({ length: 6 }).map((_, i) => (
    <div key={i} style={{ background:'#f0faff', padding: 16, borderRadius: 4, textAlign: 'center', color:'#1a1a1a' }}>
      <strong>Card {i + 1}</strong>
      <p style={{ margin: '8px 0 0 0', fontSize: '12px', color: '#666' }}>Auto-fits at 220px min</p>
    </div>
  ))}
</div>

Tailwind doesn't ship a bare `auto-fit` utility (the column-min-width is arbitrary per layout), so this is the one pattern that reaches for an inline `gridTemplateColumns` — everything else on this page is plain classes.

### Pattern 3 — Dashboard with variable-height widgets

**When to use**: analytics dashboards, admin panels with widgets of different heights.

```tsx
<div className="grid grid-cols-3 grid-rows-3 gap-4">
  <div className="row-span-2"><ChartWidget /></div>
  <div><MetricCard title="Revenue" value="$45k" /></div>
  <div className="row-span-3"><ActivityFeed /></div>
  <div><MetricCard title="Users" value="1.2k" /></div>
  <div className="col-span-2"><TableWidget /></div>
</div>
```

<div className="grid grid-cols-3 grid-rows-3 gap-4" style={{ border: '1px solid #e5e7eb', padding: 8, borderRadius: 6, marginTop: 12, minHeight: 300 }}>

### Pattern 4 — Sidebar layout (fixed + flexible)

**When to use**: app shells, documentation sites, admin panels.

```tsx
<div className="grid grid-cols-1 gap-4 md:grid-cols-[250px_1fr]">
  <aside><Sidebar /></aside>
  <main><Content /></main>
</div>
```

<div className="grid grid-cols-1 gap-4 md:grid-cols-[250px_1fr]" style={{ border: '1px solid #e5e7eb', padding: 8, borderRadius: 6, marginTop: 12 }}>
  <aside style={{ background:'#f7fafc', padding: 16, borderRadius: 4, color:'#1a1a1a' }}>
    <strong>Sidebar</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '12px', color: '#666' }}>Fixed 250px from md up</p>
  </aside>
  <main style={{ background:'#edf2f7', padding: 16, borderRadius: 4, color:'#1a1a1a' }}>
    <strong>Main Content</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '12px', color: '#666' }}>Flexible width</p>
  </main>
</div>

Tailwind's arbitrary-value syntax (`grid-cols-[250px_1fr]`) covers the legacy system's `.grid-cols-sidebar` preset — there's no need for a named utility for a one-off column template.

---

### Pattern 5 — Column ordering (responsive reorder)

**When to use**: show content first on mobile, sidebar first on desktop, without changing DOM order.

```tsx
<div className="grid grid-cols-1 gap-4 md:grid-cols-2">
  <main className="order-2 md:order-1"><Content /></main>
  <aside className="order-1 md:order-2"><Sidebar /></aside>
</div>
```

<div className="grid grid-cols-1 gap-4 md:grid-cols-2" style={{ border: '1px solid #e5e7eb', padding: 8, borderRadius: 6, marginTop: 12 }}>
  <main className="order-2 md:order-1" style={{ background:'#e5edf4', padding: 16, borderRadius: 4, color:'#1a1a1a' }}>
    <strong>Main Content</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '12px', color: '#666' }}>Second on mobile, first from md up</p>
  </main>
  <aside className="order-1 md:order-2" style={{ background:'#0b4bff', color: 'white', padding: 16, borderRadius: 4 }}>
    <strong>Sidebar</strong>
    <p style={{ margin: '8px 0 0 0', fontSize: '12px' }}>First on mobile, second from md up</p>
  </aside>
</div>

Note the direction — this example deliberately shows main content ordered *after* sidebar in source but *first* visually below `md`, the opposite of Pattern 1. Reorder visually only; keep source order logical for screen readers.

## Complete Utility Reference

| Category | Classes |
|---|---|
| Container | `grid` |
| Columns | `grid-cols-{1-12}`, `col-span-{1-12}`, `col-span-full`, `col-start-{1-13}`, `col-end-{1-13}` |
| Rows | `grid-rows-{1-6}`, `row-span-{1-6}`, `row-span-full`, `row-start-{1-7}`, `row-end-{1-7}` |
| Gap | `gap-{N}`, `gap-x-{N}`, `gap-y-{N}` (full spacing scale, 0–96) |
| Flow | `grid-flow-row`, `grid-flow-col`, `grid-flow-dense`, `grid-flow-row-dense`, `grid-flow-col-dense` |
| Alignment (items) | `items-start`, `items-center`, `items-end`, `items-baseline`, `items-stretch` |
| Alignment (content) | `justify-start`, `justify-center`, `justify-end`, `justify-between`, `justify-around`, `justify-evenly` |
| Combined placement | `place-items-{start\|center\|end\|stretch\|baseline}`, `place-content-{start\|center\|end\|between\|around\|evenly\|stretch}` |
| Ordering | `order-{1-12}`, `order-first`, `order-last`, `order-none` |
| Aspect ratio | `aspect-square`, `aspect-video`, `aspect-[N/M]` (arbitrary ratios) |
| Container | `container` (customized max-width, see above) |
| Responsive prefix | `sm:`, `md:`, `lg:`, `xl:`, `2xl:` — prepend to any class above |

Any class not covered by a named utility (an unusual column template, a one-off ratio) is available via Tailwind's arbitrary-value syntax: `grid-cols-[200px_1fr_200px]`, `aspect-[21/9]`.

## Comparison with the Legacy Grid

| | This page (Tailwind) | [Foundations/Grid Legacy](?path=/docs/foundations-⚠️-grid-legacy--docs) |
|---|---|---|
| Use for | All new work, all `ui/*` components | Only the ~26 existing legacy MUI marketing pages/sections that already use it |
| Breakpoints | `sm:640 md:768 lg:1024 xl:1280 2xl:1536` | `sm:576 md:768 lg:1024 xl:1200 xxl:1540` — differs at every tier except md/lg |
| Responsive syntax | Prefix: `md:col-span-6` | Suffix: `mds-legacy-col-md-6` |
| Column span | `col-span-{N}` (of however many `grid-cols-N` defines) | `mds-legacy-col-{N}` (of 12) |
| Container max-width | 1540px (customized to match) | 1540px (native) |
| Gap scale | Same 4px base, `gap-{N}` | Same 4px base, `mds-legacy-gap-{N}` |
| Import needed | None | `_grid.scss`, loaded globally via `global.scss` |

Never mix the two systems' classes on the same element — they use CSS Grid differently and their column-span math doesn't reconcile (12-column vs. whatever `grid-cols-N` you set).
