# Elevation

Elevation communicates layering, interactivity and focus. We keep a compact shadow scale to reduce visual noise.

<div style={{
  background: '#fff3e0',
  padding: '16px 20px',

  <strong>Is this Tailwind?</strong> No — the scale below is MDS's own (<code>src/shadows.ts</code>, 6 levels, each with a
  documented semantic usage), not Tailwind's default shadow scale (<code>shadow-sm</code>, <code>shadow-md</code>,
  <code>shadow-lg</code>, <code>shadow-xl</code>, <code>shadow-2xl</code>). Unlike grid, this hasn't
  been reconciled yet: several <code>src/components/ui</code> components (button, chart, context-menu, dialog,
  dropdown-menu, input, input-group, menubar, message-scroller, questionnaire, select, sheet, stat-card, textarea, toast)
  currently reach for Tailwind's bare shadow utilities directly instead of this scale — a real, undocumented
  split worth reconciling later, not addressed on this page yet.
</div>

## Guidelines

- Prefer the lowest possible level that provides adequate separation.
- Use level 0 for nested containers and cards on tinted backgrounds.
- Level 1–2 for standard cards and interactive surfaces.
- Level 3 for transient layers like menus, popovers.
- Level 4 for dialogs and blocking UI.
- Level 5 reserved for critical overlays (rare).

## Accessibility & Theming
Always ensure sufficient contrast between elevated surface and the background. In dark mode, reduce shadow spread intensity; consider using subtle border + low alpha shadow combination.
