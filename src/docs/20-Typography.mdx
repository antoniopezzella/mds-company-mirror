# Typography

System typography leverages `Noto Sans` for body text and `MMC Display` for headings & key UI labels.

<TypographyTable />

## Guidance
- Use semantic heading levels (`<h1>`…`<h6>`) according to document hierarchy.
- Keep display (MMC Display) usage purposeful: section titles, dashboards, key metrics.
- Avoid inline font overrides—add a variant to the theme if reused.
- Ensure accessible contrast and sufficient size for readability.
