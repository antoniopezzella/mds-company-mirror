# Spacing

Consistent spacing ensures rhythm and visual clarity. We use a curated scale mixing 4px micro steps and larger 8px multiples.

## Usage Guidelines
- Prefer container padding of 16 / 24 / 32 depending on breakpoint.
- Vertical rhythm in dense panels: multiples of 8.
- Dashboard section gutters: 32–48.
- Avoid ad‑hoc pixel values; add to the scale before use.

## API Integration
The theme `spacing` function is overridden. Use:

```tsx
sx={{ p: 3, gap: 2 }} // maps to spacing indices -> px
```
