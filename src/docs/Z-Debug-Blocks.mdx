# Blocks Debug

Minimal verification of core doc blocks (Meta, Story, Controls). Use to isolate addon-docs regressions.

This page intentionally avoids referencing specific component stories to prevent Storybook from indexing it as a component docs page.

---
If failure persists:
- Ensure `@storybook/addon-docs` version matches `@storybook/react-vite`.
- Temporarily remove the alias in `.storybook/main.ts` to test direct import.
- Clear cache: `npm run storybook:clean`.
- Remove all but this MDX file from `stories` globs to isolate.
