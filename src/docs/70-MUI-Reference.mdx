# MUI Reference

Raw Material UI component examples are collected here as a neutral baseline before applying Marsh Design System role-driven theming.

> Purpose: Provide quick visual + usage parity with upstream MUI docs using our ThemeProvider (light/dark) and typography variables. No role color overrides are applied yet beyond existing global theme.

## Scope (Phase 1)

Included (Core only): Inputs, Data Display, Feedback, Surface, Navigation, Layout, Utils.

Deferred (Future): MUI X (Data Grid, Date/Time Pickers, Charts), Lab (Masonry, Timeline), Pro/Paid components.
