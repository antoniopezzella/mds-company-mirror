# Blocks Canary

This minimal page contains only a single `<Meta />` and a heading. It is used to confirm
that MDX compilation and the docs blocks import path is functioning before
introducing `<Story />` or other advanced blocks (e.g., `<Controls />`).

If this page fails to load, the issue is unrelated to advanced Doc Blocks usage.

---
---
This page intentionally contains no story references to avoid interfering with the indexer while debugging.
